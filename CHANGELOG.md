# Changelog

All notable changes to this project are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-19

First release.

### Added

- `snap` skill for Claude Code (as a plugin) and for Codex, Cursor and GitHub
  Copilot (as an Agent Skills folder).
- Markdown rendering: headings, paragraphs with inline formatting, bullet,
  numbered and task lists, block quotes, rules, syntax-highlighted code and
  GitHub tables with column alignment.
- Five window themes and nine background presets, plus transparent, solid,
  multi-color and CSS-gradient backgrounds.
- PNG and JPEG output at 1x to 4x, saved to `~/Pictures/markdown-snaps/` with
  names that never overwrite.
- "Snap your last message" in Claude Code, read from the session transcript.
- First-run question for your background and theme, saved as defaults.
- Windows widen to fit wide tables.
- All Twemoji 17 emoji (including flags, skin tones, ZWJ sequences and
  keycaps), plus arrows, math and symbol characters, drawn offline.
- A warning for characters that can't be drawn correctly (scripts without a
  bundled font, and right-to-left text).
