# Security

The skill runs locally, never makes network requests, and only reads the
files you point it at (plus, in Claude Code, the current session transcript
for "snap your last message").

If you find a security problem, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/safwanidrees/markdown-snap-skill/security/advisories/new)
rather than opening a public issue. You'll get a reply within a week.
